# Web Development Stack - Docker Compose

## Deskripsi
Proyek ini merupakan implementasi lingkungan Web Development Stack menggunakan Docker Compose untuk menjalankan beberapa service dalam satu lingkungan terintegrasi.

## Teknologi yang Digunakan
1. PHP + Apache
2. Python FastAPI
3. WebSocket
4. Node.js
5. MySQL
6. PostgreSQL
7. MongoDB
8. phpMyAdmin
9. pgAdmin
10. Mongo Express
11. MQTT Mosquitto
12. RabbitMQ

## Cara Menjalankan

1. Pastikan Docker Desktop sudah berjalan.
2. Clone repository:
   ```bash
   git clone https://github.com/USERNAME/webdev-stack.git
   ```
3. Masuk ke folder:
   ```bash
   cd webdev-stack
   ```
4. Buat file `.env` berdasarkan konfigurasi environment yang diperlukan.
5. Jalankan seluruh service:
   ```bash
   docker compose up -d
   ```
6. Periksa container:
   ```bash
   docker compose ps
   ```
